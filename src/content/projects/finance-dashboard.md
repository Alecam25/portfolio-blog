## Overview

This project is a personal finance dashboard created to manage salary payments, fixed expenses, savings, and available money in a simple and organized way.

## Main Features

- Register salary payments.
- Calculate fixed expenses.
- Calculate savings.
- Show available money.
- Calculate a daily spending limit.
- Store information using Supabase.

## Technologies Used

- React
- JavaScript
- Supabase
- Vercel
- GitHub

## What I Learned

With this project, I practiced working with React components, state management, financial calculations, Supabase integration, and deployment using Vercel.
